Importante sobre o Histórico

Ao importar o histórico, o sistema apenas cadastra esses leads no banco de dados local.

  • Nenhum arquivo de saída será gerado.
  • Leads que já existem no banco com o mesmo Nome/Email/Telefone serão ignorados automaticamente (sem criar duplicatas internas).
  • Você pode fazer múltiplos uploads históricos de planilhas diferentes para juntar todas no banco.
